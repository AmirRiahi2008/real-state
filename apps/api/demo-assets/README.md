# Illustrative property photography

These stock photographs illustrate the fictional demo catalogue. They do not depict an advertised UAE unit and must not be presented as evidence of an available property. The seeded descriptions disclose that distinction.

Sources are recorded in [sources.json](sources.json). The photographs are downloaded from Unsplash under the [Unsplash License](https://unsplash.com/license), which permits downloading, copying, adapting and using these images in a website, including commercial use. This application does not resell the unmodified photographs or provide a competing image library.

The local WebP copies avoid third-party image requests when visitors browse the catalogue. To deliberately refresh the assets from their recorded public sources, run `node apps/api/demo-assets/download.mjs` from the repository root. Database seeding itself never downloads arbitrary remote URLs.

`original-demo.webp` is the synthetic building illustration generated by the original seed. It is not an Unsplash photograph. `storage-map.json` records the exact reserved media filenames for all nine immutable illustrations. The Replit launcher restores missing cache files with exclusive copy operations and never overwrites an existing file or changes database data. The thirteen demonstration listings share these nine media records.
